# minecraft-pack

Mod-Pack (Fabric, [packwiz](https://packwiz.infra.link/)) für den Minecraft-Server von Karl und Freunden.
Der Prism Launcher der Mitspieler gleicht die Mods bei jedem Start automatisch mit dem Branch `live`
ab; der Server ist auf einen bestimmten Commit festgelegt. Neue Stände gibt nur Karl frei.

Enthält nur die Mod-Liste (Metadaten und Prüfsummen), keine Mod-Dateien und keine Geheimnisse.
